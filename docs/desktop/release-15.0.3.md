# HEAV3NS-CODE 15.0.3 for macOS

This update improves the native workspace with a project task board, isolated
`/btw` side questions, `/compact` conversation compression, and sleep prevention
while work is running. It also restores file positions across app restarts and
branch switches, including PDF page and zoom, image zoom and pan, CSV scroll,
and code selection.

Existing installations can use **HEAV3NS-CODE → Check for Updates…**. Sparkle
updates the installed app in place and preserves workspace data. New installations
can use the signed, notarized DMG for Apple Silicon or Intel; macOS 14 or later
is required. Verify downloads with `SHA256SUMS.txt` from this release.
