# HEAV3NS-CODE Linux

Mode: **Operate**. Native GTK 4 desktop presentation of the existing LUMI
workspace protocol. Conversation and its persistent composer lead; project
navigation sits on the left and persistent task context sits on the right.
Walkthrough, Changes, Inspect and Run remain beside the conversation on wide
windows; compact windows switch between conversation and context without losing
drafts. Auxiliary account, model, memory and checkpoint editors use modeless
native windows. GTK owns system fonts, semantic colors, selection, focus, scaling and
light/dark appearance. Retain the macOS client's product intent without AppKit
or SF Symbols dependencies.

The user opens a project, directs LUMI, observes recorded work, reviews approvals
and stops execution. The same runtime owns tools, credentials, persistence,
provider choice, execution policy and project processes on both platforms.
Unsupported capabilities disable their controls. All mutations require explicit
user actions; reconnect never replays an uncertain submission.

See [Linux build and scope](../../docs/desktop/LINUX.md) for setup, implemented
workflows and remaining differences from the macOS presentation.
