# Linux native presentation

Preserve the conversation-first macOS journey using GTK 4 widgets. System theme,
font sizing, native header bars, file chooser portals, list selection and focus
provide platform behavior. Blue user-message tint derives from the theme's
selection color and is reinforced by the explicit **You** role. Agent replies
remain selectable prose; code, command arguments and diffs use monospaced text.

A resizable 225-point navigation pane supports a flexible conversation and
persistent composer. Conversations toggles navigation for compact workspaces;
secondary inspections open separate modeless windows so Stop and the composer
remain available. Evidence readers page large output rather than growing memory
without bounds. Approval panels show the reason, tool, scope and scrollable exact
arguments before Deny and Allow once. No default key approves an operation.

Keep unknown outcomes, disconnected state, draft-save errors, stale revisions
and inspection limits visible. Runtime capability checks gate optional tools.
Project commands and checkpoint restores use the existing reviewed runtime
contracts; browser preview is an explicit action restricted to local HTTP(S).
